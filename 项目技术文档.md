# PillPal — 技术文档

> **版本**：v2.0 | **日期**：2026-05-14 | **分支**：v5

---

## 一、项目概述

**NestJS + TypeScript + Taro + React** 全栈项目。

| 端     | 技术栈                                        | 目录           |
| ------ | --------------------------------------------- | -------------- |
| 后端   | NestJS 11 + Prisma 7 + MySQL + Redis          | `server-nest/` |
| 前端   | Taro 3.6.38 + React 18 + TypeScript + Zustand | `app-taro/`    |
| 数据库 | MySQL 8.0 `family_medicine`               | —              |

## 二、后端架构

| 模块                  | 文件            | 路由数 | 职责                                                 |
| --------------------- | --------------- | :----: | ---------------------------------------------------- |

## 五、当前不足

### 5.1 微信推送不可用

| 问题     | 现状                                |
| -------- | ----------------------------------- |
| 模板ID   | `.env` 中仍为 `your-template-id`    |
| 用户订阅 | `user_subscriptions` 表为空         |
| 提醒设置 | `user_notification_settings` 表为空 |

**影响**：用药提醒只能在小程序内查看 pending 记录，无法通过微信服务通知推送到手机。

**修复**：

1. 在 `mp.weixin.qq.com` → 订阅消息 → 申请「用药提醒」「药品过期提醒」模板
2. 将模板ID填入 `.env` 的 `WECHAT_EXPIRY_TEMPLATE_ID` 和 `WECHAT_MEDICATION_TEMPLATE_ID`
3. 用户在「提醒设置」中订阅通知

### 5.2 Socket 未连接

WebSocket 网关已初始化但客户端连接超时（非关键，数据通过 HTTP API 正常获取）。

### 5.3 前端需改进

| 问题                | 说明                                             |
| ------------------- | ------------------------------------------------ |
| 头像路径            | 硬编码 `192.168.31.90:3001`，切换网络需手动修改  |
| API 基址            | 同上，分布 `api.ts` 和 `socket.ts` 两处          |
| TabBar 手动注入     | 每个 Tab 页面需手动 `<CustomTabBar />`，不够优雅 |
| mock 数据           | 覆盖不全，部分读操作无降级                       |
| scroll-view padding | 微信基础库 3.0.2 不支持 padding 属性             |

### 5.4 后端需改进

| 问题          | 说明                                         |
| ------------- | -------------------------------------------- |
| BigInt 序列化 | 依赖 `BigInt.prototype.toJSON` 全局 polyfill |
| 种子数据      | 日期仍为 2023 年，需更新                     |
| 日志          | 部分异常静默处理，排查困难                   |

### 5.5 安全

| 问题       | 说明                              |
| ---------- | --------------------------------- |
| JWT Secret | `your-access-secret-key` 为弱密钥 |
| 数据库密码 | 硬编码在 `.env`，未加密           |
| CORS       | `app.enableCors()` 允许所有来源   |
